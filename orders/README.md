# История заказов Пироговой

Дашборд: https://imperil03.github.io/pirogi86/orders/

Три раздела: «Заказы», «Товары и улицы», «Покупатели».
Исходный срез заказов — 25 октября 2026 года, 13:43 по Сургуту. Обновление ручное.

Вторая версия собрана из локального исходного проекта с русским интерфейсом. Все публичные агрегаты встроены в HTML; отдельный API и полные клиентские записи не нужны. `release.json` фиксирует SHA-256 сборки и контрольные числа.

Обзор сохраняет все 66 950 основных записей. Новые рейтинги и покупатели исключают явные отмены. Товары ранжируются по числу разных заказов с ними; антитоп ограничен положительными покупками товаров текущего меню. Улицы показываются без номеров домов.

Клиентская аналитика относится ко всей истории. Публичный топ содержит только маски последних четырёх цифр. Полные телефоны и HMAC-ключи в HTML не включены. Денежные значения отражают стоимость оформленных заказов; средние используют только полные денежные совокупности, окна 90/365 суток — только завершённое наблюдение.

Для обновления пересобирается существующий локальный проект `analytics/order-history/app` по его инструкции. Исходная SQLite и приватное соответствие покупателей остаются локально. Корневой маркетинговый аудит независим от этого раздела; прежний снимок первой версии сохранён для совместимости отката.
