# История заказов Пироговой

Интерактивный дашборд: https://imperil03.github.io/pirogi86/orders/

Срез базы: 25 октября 2026 года, 13:43 по Сургуту. Обновление ручное.
Пять блоков: годы, месяцы и сравнение лет, средний чек, единицы товара в заказе, дни недели оформления.

Публичный JSON содержит только дневные агрегаты, определения и контрольные итоги. Построчные заказы, адреса, контакты и исходная SQLite-база сюда не включены.
Основной набор — 66 950 записей; 50 структурно неполных записей остаются в локальном карантине. Это история базы сайта, не подтверждённая история всех каналов Пироговой.
Средняя стоимость рассчитана по 65 469 известным суммам; это не фактическая выручка. На графике дней недели учитываются календарные дни без записей и исключаются неполные граничные дни.

Для обновления требуется пересобрать проверенный локальный проект `analytics/order-history/app`, сверить агрегаты с подготовленной SQLite, затем заменить HTML и связанный с ним файл снимка одним коммитом. Имя снимка содержит SHA-256; нельзя менять его содержимое без смены имени и пересборки ссылки. Корневой маркетинговый аудит независим от этого раздела.
